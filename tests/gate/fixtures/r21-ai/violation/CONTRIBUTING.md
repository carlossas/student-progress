# Contributing

## Setup

Run `pip install -r requirements.txt`, then `pytest`.

## Our rules

- Personal information such as a student's name, email address or date of birth must never be written to the application logs.
- Data about students under 18 must not be sent to analytics or support tools unless it is reduced to the minimum and there is a legal reason written in the pull request.
- Every stored dataset needs a retention period; for children it can be kept 90 days at most.
